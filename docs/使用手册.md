# 使用手册

面向使用者的完整操作说明。不需要任何编程知识，照着点就行。

---

## 一、安装

1. 打开 **https://github.com/JiuZhang-9/promptpair/releases/latest**
2. 在页面最上面的 **Assets** 里点 `PromptPair-Setup-x.y.z.exe` 下载
3. 双击运行。Windows 会弹出蓝色提示「Windows 已保护你的电脑」
4. 点 **更多信息** → **仍要运行**
   （因为安装包没有购买代码签名证书，这不代表软件有问题）
5. 选择安装位置 → 下一步 → 安装
6. 桌面上出现 **PromptPair** 图标，双击打开

首次打开会自动在 `文档\PromptPair` 创建素材库。

> **以后升级不用再来下载**：程序启动时会自动检查更新，发现新版本会在后台下载完，
> 弹窗问你要不要重启安装，点「立即重启」即可。

> **重要**：卸载软件**不会**删除素材库。素材库一直在你的文档目录里，与安装目录完全分离。

### 布局与卡片快捷操作

- **设置**现在是居中弹窗，不再占用右侧；`Esc`、右上角 X、点弹窗外都能关。
- **界面大小**：设置 → 外观 → 界面大小，可选 90%–110%；默认字号已经整体放大，这个滑杆是在放大的基础上再微调。
- **顶栏面板图标**：左边控制左栏，右边控制右栏；对应 `Ctrl+B` / `Ctrl+Shift+B`。收起状态会记住，下次启动保持。
- **卡片打星**：卡片左下角星条默认半透明；鼠标移到卡片上会变实、变亮，并带缓慢呼吸光晕。点第 N 颗评分；再点同一颗不会清零，点星条右上角的 `×` 才清除。详情里也有「清除」按钮。
- **卡片收藏**：卡片右上角星形按钮，点一下收藏/取消；已收藏时常驻实心。
- **标签即筛选**：点卡片上的标签会只看这个标签；再点一次取消。多标签组合仍在左栏标签里操作。
- **复制提示词**：鼠标移到卡片上，点复制图标；或选中卡片后按 `Ctrl+C`。详情面板里还有「复制全部」（正向 + 负向 + 备注 + 生成参数）。
- **缩放卡片**：在画廊里按住 `Ctrl` 滚动滚轮，卡片在 120–380px 之间变化；普通滚轮还是上下滚动。
- **框选**：在画廊空白处按住左键拖一个框，框到的卡片会被选中；按住 `Ctrl` 拖拽是追加选中；拖到上下边缘会自动滚动。
- **取消选中**：在画廊空白处单击，会清空选中、关闭右侧详情，并收起底部悬浮条。

## 三、录入（三种方式，按场景选）

### 方式 1：拖拽 + 粘贴（最常用）

1. 点右上角 **录入 → 手动新建**（或按 `Ctrl+N`）
2. 把图片/视频从资源管理器**直接拖进**编辑窗口的媒体区
   - 也可以点「粘贴剪贴板图片」，或直接 `Ctrl+V`
3. 在「正向提示词」里**粘贴提示词**
4. 打标签（输入标签名回车；没见过的词回车即新建）
5. 需要的话展开「负向提示词 / 生成参数 / 备注」补全
6. 点 **保存记录**

> 一个小技巧：先复制提示词，再拖图，最后在提示词框里 `Ctrl+V`，一气呵成。

### 方式 2：整目录批量导入（迁移旧素材）

1. **录入 → 导入整个文件夹**
2. 选一个文件夹，会**递归扫描所有子文件夹**
3. 等待进度走完

导入时会自动做这些事（可在 设置 → 导入规则 里关掉）：

| 规则 | 效果 |
| --- | --- |
| 按文件夹名打标签 | 父文件夹叫「赛博朋克」→ 自动打上同名标签 |
| 自动创建标签 | 文件夹名没见过 → 直接建成新标签 |
| 读同名提示词文件 | 旁边有 `xxx.txt` → 自动填进提示词 |
| 读 PNG 内嵌参数 | Stable Diffusion 生成的图，提示词直接写在图里，自动读出来 |
| 读 ComfyUI 工作流 | 旁边有 `xxx.json` → 自动提取提示词和模型名 |
| 连号文件合并 | `girl_1.png` `girl_2.png` `girl_3.png` → **合并成一条记录**（3 个产物共用一条提示词） |
| 识别来源平台 | 路径里有 `jimeng`/`可灵`/`midjourney` → 自动标注来源 |

> 连号合并是关键规则：一次跑出 4 张图，本来就该是一条记录，不是四条。

### 方式 3：浏览器插件采集

见下面第**八**节。

### 模型与生成参数

- 生成模型会显示在卡片标签行（虚线徽标）和详情头部，例如 `即梦 3.0`、`MJ v6.1`、`SDXL`。
- **模型从词表里选**（0.8.0 起）：编辑记录时点开「模型」，按 视频 / 图片 / 其他 分组列出词表，带使用数；输入新名字会提示「新建」，回车加入词表后再选中——不再直接产生自由文本，同一模型不会出现多种写法。
- 老库里已有的散装模型名：左侧 **工具 → 模型管理** 会把「未入词表的模型」单独列出来，一键加入词表；也可以在那里合并近似名字（例如 `即梦3.0` → `即梦 3.0`）。
- 更细的 Seed / 尺寸 / 步数 / CFG 仍在「负向提示词 / 生成参数 / 备注」里。
- AI 打标的接口模型在 **设置 → AI 打标** 里始终可见；未启用时置灰，方便先看清当前配置。

### 模型管理（词表治理）

左侧 **工具 → 模型管理**（或模型区右上角的「管理」）：

- 词表自带常用预设（即梦、可灵、Runway、Sora、Veo、MJ、SDXL、Flux…），可新建、重命名、删除，也可「恢复默认」
- 词表存在 `library.json` 里，随库搬迁、随分享包带走；条目上的模型名仍是字符串，导出与旧版本都能读
- 重命名时可勾选「同步历史」，把已有记录里的旧名字一起改掉
- 面板会列出**未入词表的历史值**和**疑似重复建议**（去空格/大小写、编辑距离 ≤ 2、名称包含），点一下即可归并
- 侧栏「模型」区点任意模型即筛选，再点取消；可与其他筛选叠加

## 四、打标签与分类

工具提供两层分类，各管一件事：

**标签**（多对多，横向）—— 描述"这是什么"
- 标签属于「标签组」，组有颜色，标签继承组的颜色
- 默认给了 5 个组：风格 / 题材 / 镜头 / 画质 / 用途，可自行改名或新建
- 一条记录可以有任意多个标签

**集合**（纵向）—— 描述"这属于哪个项目"
- 像文件夹，但**一条记录可以同时属于多个集合**
- 用来分「客户A」「视觉实验」「2026 春季项目」这类
- 左侧「集合」区点 **+** 新建

**标签的增删改**
- 新建：编辑记录时在标签输入框输入名字按回车
- 重命名 / 删除：在左侧标签上**右键**，输入新名字（或输入 `-` 删除）
- 合并：右键输入 `= 目标标签名`；也可以进「标签管理」批量合并
- 批量：多选卡片后，底部操作条 → 加标签 / 移标签

### 标签管理（治理）

标签用久了会出现「赛博朋克 / 赛博 / cyberpunk」这类同义标签。左侧 **工具 → 标签管理**（或标签区右上角的「管理」）打开治理面板：

- 标签按使用数从多到少排序，可搜索
- 勾选多个 → **合并到…**：选一个目标标签，其余标签的引用会转过去并去重，然后删除
- 单选 → **重命名**；也可以直接删除
- 面板下方会自动列出**近似重复建议**（大小写 / 空格不同、编辑距离 ≤ 2、名称包含），点「合并」即可
- 合并前会二次确认，并写清影响多少条记录

> 建议在批量打标（尤其是 AI 打标）之后定期跑一次，保持标签干净。

## 五、搜索与筛选

搜索框（`Ctrl+F`）是**全文搜**，会同时匹配：标题、正向提示词、负向提示词、备注、标签名、模型名、采样器、seed、来源平台、原始文件名。

左侧可以叠加筛选：

| 筛选项 | 说明 |
| --- | --- |
| 全部提示词 / 收藏 | 收藏用详情面板右上角的星标 |
| 集合 | 点一下选中，再点取消 |
| 类型 | 全部 / 图片 / 视频 |
| 评分 | 「3 星以上」这类 |
| 来源平台 | 列表会按数量排序 |
| 标签 | 可多选；选 2 个以上时可切换「任一 / 同时满足」 |

底部会实时显示 **当前筛选 N 条**。筛选乱了点「清除全部筛选」。

## 六、批量操作

1. 单击第一张，`Shift+单击` 最后一张（或 `Ctrl+单击` 逐张加选）
2. 底部弹出操作条：

| 按钮 | 作用 |
| --- | --- |
| 全选结果 | 把当前筛选出的全部选中 |
| 加标签 / 移标签 | 弹出标签列表，点一下即应用。加标签时可以顺手新建 |
| AI 打标 | 让模型给候选标签（需先在设置里配置接口；确认后才写入） |
| 归入集合 | 批量加入某个集合 |
| 星级 | 批量改评分 |
| 收藏 | 批量收藏 |
| 导出为分享包 | 只导出选中的这些 |
| 删除 | 批量删除（会确认） |

### AI 打标（可选）

如果配置了 AI 接口，底部操作条会多一个 **AI 打标** 按钮：

1. 设置 → **AI 打标（可选）** → 启用
2. 填 **接口地址**（OpenAI 兼容，通常以 `/v1` 结尾）、**API Key**、**模型名**（需要支持图片输入）
3. 点「测试连接」确认能通
4. 选中一批记录 → 底部 **AI 打标** → 等待候选
5. 弹层里每条记录会列出 3–6 个候选标签，默认全选；点标签可以取消
6. 点「应用 N 个标签」后才会写入；已有标签会复用，新标签会创建

说明：

- **不启用或没填 Key 时，这个入口完全不会出现**，所有现有流程照常离线工作
- 会把**缩略图、提示词和现有标签列表**发送到你配置的接口；不配置就不会发任何请求
- Key 以明文保存在本机 `%APPDATA%\PromptPair\config.json`，不会进入素材库，也不会随分享包分发
- 模型效果取决于接口和模型；候选标签只是建议，最终以你的确认为准
- 打标后建议去「工具 → 标签管理」合并一次同义标签

## 七、重复清理

左侧 **工具 → 重复图检测**。

- 同一份文件重复导入已被自动去重（按内容哈希），这里找的是**看起来一样但不是同一个文件**的近似重复（例如同一张图存了 PNG 和 JPG，或压缩过一版）
- 「严格 ←→ 宽松」滑块调判定阈值：数字越小越严格
- 每组默认把**体积最大**的标为「保留」
- 点「保留最大的，清理其余」→ 其余文件从磁盘删除，引用它们的记录里也会去掉

> 这是唯一会真正删文件的操作，会弹确认框。操作前先确认每组保留的是哪一张。

## 八、浏览器插件（通用框选采集）

**安装（只做一次）**

1. 打开 PromptPair → 右上角齿轮 **设置** → 找到「浏览器插件采集」
2. 点「插件目录」右边的 **打开**，记下弹出的文件夹路径
3. 打开 Chrome，地址栏输入 `chrome://extensions` 回车
   （Edge 用 `edge://extensions`）
4. 打开右上角 **开发者模式** 开关
5. 点左上角 **加载已解压的扩展程序**
6. 选中第 2 步打开的那个 `extension` 文件夹 → 确定
7. 工具栏出现 PromptPair 图标（可能要点拼图图标钉住）

**使用（框选图片）**

1. 在网页上**选中提示词文字**（这一步可选，但选了就能一起带走）
2. 按 `Alt+Shift+P`，或点插件图标 → **框选采集当前页**
3. 页面变暗，鼠标移到图片上会高亮
4. **单击**想要的图片 → 右下角提示「已收进 PromptPair 素材库 ✓」
5. 回到 PromptPair，记录已经在了（来源平台和页面链接都会带上）

**使用（截图采集）**

图片是画布、受保护资源，或者原图根本读不到时，用截图：

1. 同样先选中提示词文字（可选）
2. 按 `Alt+Shift+S`，或点插件图标 → **截图采集（拖框）**，也可以右键菜单选「用 PromptPair 截图采集」
3. 页面变暗后，按住左键拖出一个框，框住你要的图片区域
4. 松手后自动截图并入库，右下角提示「已收进 PromptPair 素材库 ✓」

截图保存的是**当前屏幕上看到的画面**，缩放、遮挡都会一起截进去；需要原图时优先用框选采集。

取消：按 `Esc` 或点右键。

> 如果提示「没找到正在运行的 PromptPair」，说明桌面端没开，先打开软件再采集。

> 插件 0.2.0 起支持拖框截图；0.1.1 起会先在页面里把图片读成 data URL，兼容 `blob:` 和需要登录态的图片。
> 升级软件后，记得在 `chrome://extensions` 里点一次扩展的刷新按钮，让新脚本生效。

## 九、打包带走 / 分享给别人

### 导出

右上角 **导出** 里分两类：

**分享包 `.promptpack`（可导回，含原图/视频）**

| 选项 | 用途 |
| --- | --- |
| 只导出选中的 N 条 | 精细挑选后分享 |
| 导出当前筛选结果 | 例如「只导出标签=赛博朋克的」 |
| 导出整个库 | 完整备份 |

**单页 HTML（对方双击即看、直接复制）**

| 选项 | 用途 |
| --- | --- |
| 单页 HTML（缩略图） | 文件小，适合直接发人 |
| 单页 HTML（含原图） | 对方能看原图细节，文件大；视频只放封面 |
| 分享说明 | 打开一张说明，讲清楚两种方式的区别 |

另有两个数据出口：
- **导出提示词清单 CSV** —— Excel 直接打开，适合做表格整理
- **导出全部数据 JSON** —— 纯数据，不含媒体，适合程序处理或深度备份

### 分享包里有什么

`.promptpack` 其实是一个 ZIP，里面有：

```
manifest.json        包清单
data/prompts.json    全部结构化数据（任何程序都能读）
index.html           ← 自带浏览页，双击就能看
media/               原始图片/视频
thumbs/              缩略图
README.txt           给收包人的说明
```

`data/prompts.json` 里同时带着模型词表（`models`）：导入方按名称去重并入自己的词表，旧版本会忽略这个字段，照常能打开。

**对方不需要安装 PromptPair**：

1. 把 `.promptpack` 发给对方
2. 对方把后缀改成 `.zip` 解压
3. 双击里面的 `index.html`

就能看到全部图片、搜索、按标签筛选、点开看大图、**一键复制提示词**、播放视频。

### 单页 HTML（对方双击即看）

导出 → **单页 HTML（缩略图）** 或 **单页 HTML（含原图）**。

- 产物是一个 `.html` 文件：对方双击用浏览器打开即可，**不用解压、不用安装、断网也能看**。
- 卡片上直接有「复制提示词」；点开详情还能「复制全部」（正向 + 负向 + 参数）和「复制参数」。
- 缩略图模式文件小，适合直接发人；含原图模式能看原图细节，文件会大很多。
- 视频在单页里只放封面；要对方播放原视频，用 `.promptpack`。
- 单页 HTML 不能导回软件；要导回请用 `.promptpack`。
- 含原图模式超过约 200MB 时会提示改用缩略图或分享包。

> 不确定选哪个？右上角 导出 → **分享说明**，里面有一页对比。

### 导入别人给的包

**录入 → 导入分享包** → 选文件 → 弹窗问两种方式：

| 方式 | 结果 |
| --- | --- |
| 合并到当前库 | 内容并进现有库。同名标签/集合自动对齐，媒体按哈希去重，不重复占空间 |
| 作为新库打开 | 在「文档」下新建一个独立库，只含这个包的内容 |

## 十、备份与换电脑

素材库是**自包含**的，路径：`文档\PromptPair`

**备份**：直接复制这个文件夹到移动硬盘或网盘。
**换电脑**：把整个文件夹复制到新电脑的 `文档` 下，装好软件打开即可（设置 → 素材库 → 更换位置 可以指到任意盘）。

三个文件的作用：

| 文件 | 作用 |
| --- | --- |
| `library.json` | 全部数据（文本），**最重要** |
| `library.json.bak` | 上一次保存的自动备份 |
| `media/` `thumbs/` | 原始文件与缩略图 |

> 万一 `library.json` 坏了打不开：把 `library.json.bak` 改名成 `library.json` 覆盖回去，能恢复到上一次保存的状态。

## 十一、自动更新

- 打开软件 8 秒后自动检查新版本，之后每 4 小时一次
- 有新版本会自动在后台下载（不打扰你）
- 下载完成后弹窗：「新版本已就绪」，点 **立即重启** 即完成升级
- 也可以随时在 设置 → 更新 → **检查更新** 手动触发

升级只替换程序文件，**素材库不受任何影响**。

## 十二、常见问题

**Q：卡片里的图是空白/裂图？**
媒体文件被移动或删除了。素材库目录下的 `media` 文件夹不要手动改动。

**Q：导入后提示词是空的？**
说明图旁边没有 `.txt` 文件、PNG 里也没内嵌参数。这是正常的——不是所有生成器都会写元数据。可以单独编辑补上。

**Q：某个文件夹导入后标签打得很奇怪？**
自动打标是把**父文件夹名**当标签。如果你用的是 `2026\03\新建文件夹\img.png` 这种结构，会打出无意义的标签。建议在 设置 → 导入规则 里关掉「按文件夹名自动打标签」，或先把素材整理成 `风格名\图片.png` 的结构。

**Q：视频没有封面？**
会用系统缩略图能力抽一帧。极少数编码格式系统不支持，会显示为占位。视频原文件是完好的。

**Q：能装在 Mac 上吗？**
当前版本只提供 Windows。数据结构是跨平台的，后续可以加。

**Q：库能放多大？**
元数据是单个 JSON，十万条以内都很流畅（画廊做了虚拟滚动，只渲染可见部分）。真正占空间的是 `media`，取决于你自己放多少图。

**Q：两个窗口同时打开同一个库会怎样？**
程序做了单实例限制，第二次打开会把已有窗口拉到前台，不会出现两个进程抢写。

**Q：卸载会删掉我的图吗？**
不会。永远只删安装目录，素材库在文档目录下原样保留。
