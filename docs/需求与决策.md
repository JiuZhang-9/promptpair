## 协作规则（回应“没有我的决策”）

1. **先计划，后写代码**：每批需求先给「问题 / 备选 / 默认值 / 验收标准」，你批准后才开始。
2. **不擅自扩范围**：实现过程中发现的新问题，先记到本文件，不顺手塞进当前批次。
3. **发版单独确认**：commit / tag / push 属于发版动作，做完功能先给你验收，再决定是否发布。
4. **决策留痕**：你改过的默认值、放弃的方案、推迟的功能，都写回这张表。
